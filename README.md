# Sri Mallikarjuna Bramarambha Water Plant

A modern, responsive, and mobile-friendly website for a local 20L water can delivery business located in Cumbum Town, Markapuram.

## Project Structure

```
/water-plant-website
│
├── index.html        (Home Page)
├── about.html        (About Us Page)
├── services.html     (Services Page)
├── contact.html      (Contact & Order Page)
├── css/
│   └── style.css     (Main Stylesheet)
├── js/
│   └── script.js     (Interactions, Nav, Dark Mode)
├── images/
│   ├── water-can.png (Product Image)
│   └── hero-bg.png   (Background Visuals)
└── README.md         (Project Documentation)
```

## Features
1. **Modern UI/UX**: Clean blue and white theme representing pure water.
2. **Fully Responsive**: Adapts perfectly to mobile devices and desktops.
3. **Dark/Light Mode**: Toggle button integrated for better accessibility.
4. **Sticky Navigation**: Smooth scrolling and mobile hamburger menu.
5. **Floating WhatsApp**: Quick contact button for direct orders via WhatsApp.
6. **Contact Form & Maps**: Easy ordering and location finding.

## Setup Instructions
No build tools required! Simply open `index.html` in any modern web browser to view the site. You can also host this project using any static site host like GitHub Pages, Netlify, or Vercel.
